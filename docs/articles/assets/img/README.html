1. Regra Geral para Artigos e Episódios

Imagens de hero e corpo (exceto autor e ícone do site) seguem o padrão:

YYYY_MM_DD_IMAGE_NNN.png

  • YYYY_MM_DD: data de publicação do artigo (primeiros 10 caracteres do nome do HTML).
  • NNN: sequência da imagem (001 para hero, 002 em diante para complementares).
  • Quando existir hero, o og:image deve apontar para o mesmo arquivo 001.

Arquivos compartilhados, sem data no nome: foto_chri.jpg e favicon.ico.

2. Exceção para Páginas Índice de Séries

Seis séries possuem página índice própria. Nesses casos, a regra de igualdade entre data do PNG e data do nome do HTML não se aplica ao índice, pois a página reúne episódios com datas distintas.
