Guia de Convenção de Imagens do Blog

Escopo: pasta docs/articles/assets/img/.

Este documento define o padrão único para nomeação e validação de imagens de artigos e séries.

1. Regra Geral para Artigos e Episódios

Imagens de hero e corpo (exceto autor e ícone do site) seguem o padrão:

YYYY_MM_DD_IMAGE_NNN.png

  • YYYY_MM_DD: data de publicação do artigo (primeiros 10 caracteres do nome do HTML).
  • NNN: sequência da imagem (001 para hero, 002 em diante para complementares).
  • Quando existir hero, o og:image deve apontar para o mesmo arquivo 001.

Arquivos compartilhados, sem data no nome: foto_chri.jpg e favicon.ico.

2. Exceção para Páginas Índice de Séries

Quatro séries possuem página índice própria. Nesses casos, a regra de igualdade entre data do PNG e data do nome do HTML não se aplica ao índice, pois a página reúne episódios com datas distintas.

  1. Série Brasil, SDK e Soberania
    Índice: 2026_02_15_serie_brasil_sdk_soberania_index.html
    Episódios: serie_brasil_sdk_soberania_ep01 a ep07.
  2. Série Depois do debate (carreira e tecnologia)
    Índice: 2026_10_06_serie_depois_do_debate_carreira_index.html
    Artigos: ..._perguntas, ..._padroes, ..._conclusao.
  3. Série Protocolo de Lucerna
    Índice: 2026_04_20_serie_protocolo_lucerna_index.html
    Episódios: protocolo_lucerna_ep01 a ep06 e epílogo em HTML próprio.
  4. Série Recolocação e teste prático Java
    Índice: 2026_08_10_serie_recolocacao_java_teste_pratico_index.html
    Episódios: serie_recolocacao_java_teste_pratico_ep01 a ep07.

Regra prática: por episódio, manter o prefixo de data do próprio HTML. Na página índice, aceitar datas diferentes nos cartões.

3. Equalização e Validação no Disco

  • No estado atual deste repositório, não há scripts versionados com os nomes equalize_article_images.ps1 e validate_article_images.ps1.
  • Também não há artefatos versionados com os nomes MANIFEST_EQUALIZACAO_IMAGENS.txt e VALIDACAO_IMAGENS_RETRO_BLOG.txt.

Observação: para os artigos 2025_12_09 e 2025_12_10, consultar notas de execuções anteriores caso ainda haja PNG com nomenclatura antiga.
